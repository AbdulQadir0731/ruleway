Support

Ruleway is a proxy client. You supply the servers — from a provider, or your own — and the app decides what goes through them.

Getting started

  • Add a server. Home → Add Server to type one in, Scan QR Code for a code from your provider, or Paste a Link if you copied an ss://, trojan://, vless:// or vmess:// link.
  • Or add a subscription. Home → Add Subscription and paste the URL your provider gave you. The server list updates itself from then on.
  • Check it works. Tap Connectivity Test. A working node answers in milliseconds; a dead one says timeout.
  • Turn it on. Flip the switch on Home. iOS will ask once to add a VPN configuration — that profile is created on your device and points at your servers.

Common problems

“Nothing loads once I connect”

Usually no server is selected, or the selected one is dead. Ruleway fails closed on purpose: a rule pointing at PROXY with nothing behind it blocks rather than leaking straight out. Run a connectivity test and pick a node that answers.

“My subscription imported nothing”

Some providers return a different format depending on the user agent. Settings → Subscriptions → Updating lets you change it. The importer reads base64 payloads, plain link lists, and Clash YAML.

“One site is broken while everything else is fine”

Something is being proxied that shouldn’t be, or blocked that shouldn’t be. Turn on Data → Record proxy requests, load the site, and look at the log: it names the rule that caught each request. Tap the row to add a rule sending that host DIRECT.

“Which rule would catch this?”

Config → Test a Rule. Type a URL and it tells you the matching rule and the policy it resolves to, without connecting.

Subscription and billing

  • Three days free, then $0.99 a month or $7.99 a year. Both plans are in one subscription group, so switching is an upgrade, not a second purchase.
  • Cancel any time before the trial ends and you are not charged.
  • Manage or cancel: Settings → Apple Account → Subscriptions. Billing is handled by Apple; we cannot see or change it.
  • Changed device or reinstalled? Open the paywall and tap Restore.
  • Refunds are handled by Apple at reportaproblem.apple.com.

Requirements

iPhone or iPad running iOS 15 or later.

Get in touch

Bugs, questions and feature requests: open an issue on GitHub. Include what you were doing, which protocol the server uses, and what the app said — never paste a server link or password into a public issue.
