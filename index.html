What’s actually in it

The engine is the product. Everything else is a way to look at it.

A real rule engine

Seventeen matchers — domain, keyword, IP range, GEOIP, ASN, process, user agent, port, time, network — with AND / OR / NOT, read top to bottom, first match wins.

Groups that choose for you

Select, URL-test, fallback, load-balance and random. Point a rule at a group and it uses whichever node is fastest, or whichever one is still answering.

It doesn’t leak

Proxied names resolve at the far end, not on your phone. QUIC and WebRTC are blocked by default so nothing slips past the rules on a protocol they don’t cover.

You can see what happened

Every request, the rule that matched it, the node it took, and the bytes it moved. Tap a row to turn it into a rule — that’s how you learn the syntax.

Config is a document

Edit it in the interface or edit the text — same object, and untouched lines keep their bytes exactly. Load it from a URL and keep your own edits on top with include.

Test before you trust

Type a URL, see which rule catches it and where it would go, without connecting. Latency tests measure an end-to-end CONNECT, not a TCP handshake.

Protocols

You bring your own servers. Ruleway speaks to them.

Shadowsocks Trojan VLESS VMess SOCKS5 HTTP / HTTPS Subscriptions Clash YAML QR import

Hysteria2, TUIC and WireGuard are registered behind the same interface and not yet dialable. The app says so in the server list rather than failing quietly.

Ruleway collects nothing

Not “anonymised”. Not “aggregated”. There is no account, no analytics SDK, no advertising identifier, and no server of ours that your traffic or your settings ever reach.
